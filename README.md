# Data-Analysis-PBA-Crime
Proyecto Realizado en mi tercer año de la Carrera de Ciencia de Datos para la materia de Analisis y Recoleccion de datos

Análisis de Seguridad Ciudadana: Delitos contra la propiedad en PBA
Proyecto académico - Universidad Nacional Guillermo Brown (UNAB)

Este proyecto realiza un análisis estadístico y exploratorio sobre los hechos delictuosos contra la propiedad en los municipios de la Provincia de Buenos Aires. El objetivo principal fue identificar patrones temporales y geográficos para comprender la evolución de la seguridad ciudadana en la región.

Tecnologías utilizadas:
Lenguaje: R
Entorno: RStudio / R Markdown
* **Librerías principales:** * `readxl`: Para la ingesta y lectura de datos desde archivos de Excel (.xlsx).
  * `ggplot2`: Para la generación de reportes visuales y gráficos.
  * `R Markdown`: Para la creación del reporte reproducible en HTML.

Mi Aporte: Conclusiones y Reflexiones
Como responsable de la etapa final del proyecto, realicé la síntesis analítica de los datos procesados:
Identificación de tendencias: Detecté los periodos de mayor incremento en delitos específicos comparando datos históricos.
Correlación geográfica: Analicé cómo ciertos municipios presentaban patrones atípicos respecto a la media provincial.
